## 一、总论

> 在开始正式介绍之前，我想起来我妈在我小的时候跟我吹牛逼，说学会了音标就可以 “看见一个词就知道它怎么读，听见一个词就知道它怎么拼”。当时把我迷得星星眼都快掉地上了。不过幼年课外班这个东西，只能说是纯传销，以至于我彻底对于英语丧失兴趣。
>
> 没想到这么多年过去了，我又把它捡起来了。

自然拼读法，指的是根据单词的拼写就可以推测它的读音；同样的，根据单词的读音就可以推测它的拼写。

中文拼音是完全可以做到，我们看到 `suí biàn` 就知道它念 “随便”，听到 “随便”，也可以写出来它的拼音是 `suí biàn`。但是对于英文就不是了，拼写和读音并不是双射，只能说只有一部分（我觉得甚至不是大部分）遵守这个规则。

经过学习，我觉得根据拼写猜读音会容易一些，但是根据读音猜拼写，就会难一些。

## 二、元音

### 2.1 音节的划分

之所以要在讲元音的发音之前讲音节的划分，是因为元音的发音非常受到音节类型的影响（其实还会受到重读 / 弱读的影响）。所以在记忆发音之前，需要先学会区分音节。我们用 `C` 代表辅音（Consonant），用 `V` 代表元音（Vowel）。这里的应该不是指字母，而是发音。

- 一个单词中有几个元音，就有几个音节。这点很好理解，人的耳朵是依靠元音（也就是发音气流不受阻碍的音）来辨别音节的。即使有些单词很长，比如说 `prompt`，它因为只有一个元音，也是只有一个音节。
- 遇到 `VCV` 的结构，要在辅音前划分音节，也就是 `V/CV` 。比如说 `pa/paer` 和 `ro/bot` 。
- 遇到 `VCCV` 的结构，要将两个辅音分开，也就是 `VC/CV`。比如说 `rab/bit` 和 `bas/ket `。
- 遇到 `CVCe` 且 `e` 在末尾的结构，这种被称 “以不发音的 e 结尾的闭音节”，是一个音节。如 `code` 是一个音节，不需要划成 `co/de` 。
- 遇到 `Cle` 且 `e` 在结尾的结构，`Cle` 部分自动组成一个音节。比如说 `ta/ble` 和 `mid/dle` 。

其实只有前 4 点规则比较 general，第 5 点规则属于是对于一些特例的概括。

在划分完成后，我们就得到了 3 种不同类型的音节：

- `CVC`：元音被辅音从两侧包裹，这种被称作闭音节。
- `CV`：以元音结尾，这种被称作开音节。
- `CVCe`：由一个闭音节和一个 `e` 结尾，这种也叫做 “magic/silent e” 现象，可以被视作开音节。

最后依然要强调，音节的划分依据的并不是**拼写**，而是**读音**。也就是说，即使我们在这里对着拼写总结了一大堆规律，实际上也用处不是很大，比如说 `mechanism` 这个单词，按照我们上面的规则，应该划分成 `me/cha/nism` 。但是实际上它划分成了 `mech/a/nism` 。

那么是不是完全没有用呢？并不是，即使出现了 `mech/a/nism` 这种不规则的音节划分，但是我们依然可以知道，这是由 `mech` 闭音节，`a` 开音节，`nism` 闭音节组成的。进而判断出它们的读音分别是 `e, ə, ɪ` 。我们只是不再能确定地划分音节了，但是在知道音节之后，我们依然可以较为确定地确定读音了（是的，依然只是 “较为确定”）。

### 2.2 闭音节与短音

对于闭音节，元音字母一般会发 “短音”，更具体来说，由如下对应：

| 字母 | 音标 | 示例           |
| ---- | ---- | -------------- |
| a    | /æ/  | cat, bad, map  |
| e    | /ɛ/  | bed, red, ten  |
| i    | /ɪ/  | sit, big, him  |
| o    | /ɒ/  | hot, not, box  |
| u    | /ʌ/  | cut, sun, luck |

> 顺带说一下，/æ/ 和 /ɛ/ 都是 “唉” 的音，但是 /æ/ 张嘴要比 /ɛ/ 大，所以在听感上面，/æ/ 会更像 “啊”，而 /ɛ/ 会更像 “诶”。

### 2.3 开音节与长音

而对于开音节，或者 magic e 音节，那么元音字母就会发它字母本身的音，也就是 “长音”：

| 字母 | 音标          | 例子                  |
| ---- | ------------- | --------------------- |
| a    | /eɪ/          | name, make, late      |
| e    | /iː/          | these, scene, me      |
| i    | /aɪ/          | time, like, five      |
| o    | /oʊ/          | home, note, go        |
| u    | /juː/ 或 /uː/ | cute, use, tube, rule |

### 2.4 Vr 组合

如果是一个元音字母后跟着一个 `r` ，那么情况又会发生变化：

| 字母         | 音标         | 例子                         |
| ------------ | ------------ | ---------------------------- |
| ar           | /ɑr/         | car, far, hard, start        |
| er / ir / ur | /ɜr/         | her, term, bird, first, turn |
| or           | /ɔr/ 或 /ɜr/ | work, for, short             |

### 2.5 双元音字母

这个部分就基本上没有什么规律了，或者说，没有什么好记的规律了，不同的元音字母组合在一起，有的会固定对应一个没有道理的发音，有的甚至会对应多个发音。

不过我看到一个很有趣的说法，是如果两个元音字母出现在一起，就猜第一个元音的长音就好了，比如 `ea` 就发 /iː/ 的音，比如说：

| 字母   | 音标 | 例子                       |
| ------ | ---- | -------------------------- |
| **ea** | /iː/ | tea, sea, eat, meat, speak |
| **ai** | /eɪ/ | rain, train, paid, main    |
| **oa** | /oʊ/ | boat, road, coat, soap     |
| **ee** | /iː/ | see, tree, feet, green     |

### 2.6 重读与弱读

音节又可以分为重读音节和弱读音节。再次强调，我们之所以要区分它们，是因为重读音节和弱读音节的元音发音是不同的。弱读音节的元音，就不是我们上面的讨论了，而是发 /ə/ 的音（也就是最轻松的元音）。

同样的，重读和弱读也有一定的规则：

- 两音节的名词 / 形容词常前重音，动词常后重音：比如对于 `present` 这个词，当它是名词 / 形容词的时候，它念作 `PREsent`，而当它是动词的时候，它念作 `preSENT`。类似的还有 `record`，`object` 和 `contract` 。
- 重音往往出现在后缀的前一个音节：比如 `inforMAtion`，``deCIsion ` 和 ` techNIcian` 。
- 前缀一般不是重音。
- 复合名词常前重音：如 `BLACKboard` 和 `NOTEbook` 。

但是同样的，这些规则，也是时灵时不灵，不用太放在心上。

## 三、辅音

### 3.1 c/g 软硬音

c/g 软硬音指的是 c/g 这两个辅音，会根据后面元音的不同有不同的读音：

| 字母      | 音标 | 例子                |
| --------- | ---- | ------------------- |
| c + a/o/u | /k/  | cat, cut            |
| c + e/i/y | /s/  | city, cent, cycle   |
| g + a/o/u | /g/  | gay, guy            |
| g + e/i/y | /dʒ/ | general, giant, gym |

### 3.2 两个辅音只有一个发音

当两个辅音连在一起，并且出现在开头的时候，经常会只读一个字母的现象：

| 字母 | 保留 | 音标 | 例子                |
| ---- | ---- | ---- | ------------------- |
| ps-  | s    | /s/  | psychology, pseudo  |
| mn-  | n    | /n/  | mnemonic            |
| kn-  | n    | /n/  | knife, know, knight |
| wr-  | r    | /r/  | write               |

### 3.3 固定搭配

这个同样没有什么道理了，就只能死记硬背：

| 字母 | 音标       | 例子         |
| ---- | ---------- | ------------ |
| ph   | /f/        | photograph   |
| qu   | /kw/       | queen        |
| gh   | /f/ 或 /g/ | laugh, ghost |
